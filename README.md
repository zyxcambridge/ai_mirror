# AI 显示器/镜子

本项目旨在帮助夫妻在争吵时缓解情绪、促进沟通，适用于智能显示器、镜子或网页端。

## 主要功能

1. **实时字幕投射**
   - 将攻击性语句自动转换为"I feel..."句式，帮助表达真实感受，减少冲突。
   - 例：
     - "你从不帮忙" → "我感到家务压力较大，希望能得到更多帮助"
     - "你总是迟到" → "我感到时间对我很重要，等待让我有些焦虑"

2. **呼吸引导（478呼吸法）**
   - 动态动画引导用户进行478呼吸法：吸气4秒→屏息7秒→呼气8秒。
   - 有助于快速平复情绪，恢复理智。

3. **记忆唤醒**
   - 随机播放夫妻过往甜蜜时刻的相册照片（需预先授权访问或配置图片链接）。
   - 通过回忆美好时光，缓解紧张气氛。

## 使用方式

- 推荐部署在网页端，支持全屏显示，适合家庭大屏、智能镜子等场景。
- 可根据实际需求扩展语音识别、本地相册访问等功能。
